# HSUF public candidate

Node.js ESM, Node 22+. Preserve exact model, revision, memory, wireless and SKU identity. Search and Judge provide untrusted candidates; only Core Audit decides fill. Provider failure is review, never blank.

Public data classification is per-record: PUBLIC_SOURCE_ONLY for independently documented manufacturer pages, SYNTHETIC for examples/tests. Legacy catalogue identifiers and private mappings stay outside this tree. Do not publish UNKNOWN records. Private overlays are optional, local, ignored and excluded from release allowlists.

Run npm test, npm run validate, npm run release:build. Do not choose a license, push or publish without user authorization. Update this project's HANDOFF.md once after the task.
