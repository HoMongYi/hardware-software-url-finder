# HSUF Implementation Plan

> For agentic workers: use superpowers:executing-plans; main agent owns all edits.

**Goal:** Build a tested v0.1.0 public candidate without company integrations.

**Architecture:** Registry-first Core shared by CLI/HTTP/MCP; optional bounded research pipeline with independent Core Audit. Canonical Skill generates Plugin.

**Tech Stack:** Node 22+ ESM, Ajv, tldts, ipaddr.js, YAML, CSV parser, stable MCP SDK.

**Spec:** ../specs/2026-10-01-hsuf-design.md

## Global Constraints

- No push, release publish or license choice.
- Core final audit overrides Judge. Offline never uses providers.
- Raw catalogue mappings cannot enter public tree. Unknown provenance means needs-refresh.

## Review Focus

- D4/D5, WiFi7/WiFi and revision ambiguity never merge.
- Redirects, DNS rebinding, body overflow and private IP never bypass network guard.
- Bad CSV/JSON and unsafe output cells fail safely or are escaped.
- Provider refusal, schema mismatch and empty search produce review.
- Private data never leaks through packaging, MCP status or exception logs.

## Tasks

1. Baseline (complete): immutable v2.2.1 104 golden + 4 integrity; verify ZIP hash.
2. Core/Registry: write behavior tests; observe missing-feature failures; implement schemas, normalize, rules, lifecycle, conflicts, audit, CSV contracts. Verify tests.
3. Providers/Research: test contracts, top-five, Judge bypass and audit override; implement bounded safe fetch, mock/SerpAPI/generic Search, mock/OpenAI/generic/command Judge; verify with local transports, no paid requests.
4. Interfaces: test CLI/CSV, every HTTP route, official SDK MCP client discovery/calls and result schemas; implement shared interfaces.
5. Migration: reproducible source hashing, metadata removal, publicly documented source URLs and safe rule/alias projection; all unknown exact mappings quarantined. Compare legacy cases under intentional safer policies.
6. Packaging/docs: verify canonical Skill with official validator; generated Plugin path/schema/hash; allowlisted releases and private leak scan; execute README examples using fixtures/local servers; final tests/build/security report.

## Execution rulings

- New v0.1.0 subdirectory is isolated; existing ZIPs and baseline never overwritten. No existing Git repository to branch.
- User explicitly requests uninterrupted execution; approval handoffs in skills do not apply.
- Live paid provider tests require separate opt-in; credentials are not sought from unrelated projects.
