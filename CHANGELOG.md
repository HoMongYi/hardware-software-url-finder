# Changelog

## 0.1.0

First public release.

### Added

- Hardware software URL resolution Core with independent URL/page audit
- Vendor and software ecosystem Registry
- Exact model, revision, wireless and SKU protection
- `fill / blank / review` decision model
- Hard filters, candidate scoring and top-five reference pipeline
- SerpAPI search and OpenAI Responses Judge providers
- Mock and generic HTTP providers; Command Judge
- CLI, CSV batch processing and legacy CSV export
- Local HTTP API and MCP server
- Shared Agent Skill for Codex and Claude Code
- Portable Codex Plugin package with bundled runtime
- Offline Registry mode
- Software lifecycle tracking
- Public Registry / optional Private Overlay separation
- MIT License and public repository metadata

### Registry scope

51 vendors, 85 domain candidates, 58 rules, 24 software ecosystems, 2 active exact models and no public aliases. All 24 ecosystems remain needs-refresh. Unverified mappings and aliases are excluded; paid Provider calls and Agent host UI activation were not run.
